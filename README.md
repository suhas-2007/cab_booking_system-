# Ride Booking System

A C++-based Ride Booking System that simulates a real-world ride booking application using Object-Oriented Programming concepts.

## Overview

The system allows users to book rides for themselves or others, select vehicles, choose driver preferences, find eligible drivers, and generate complete booking details.

## Features

* Book rides for yourself or someone else
* Car selection: Sedan and SUV
* Bike selection: Scooty and Motorbike
* Auto selection
* Driver filtering based on vehicle, gender, and availability
* Ride date and time selection
* Driver rating and average rating calculation
* Automatic fare calculation
* Estimated ride duration
* 4-digit OTP generation
* Pickup and destination management
* Driver allocation simulation
* Booking details and ride summary

## How to Run

Compile:

```bash
g++ main.cpp RideBookingSystem.cpp -std=c++11 -o RideBookingSystem
```

Run:

```bash
./RideBookingSystem
```

For Windows:

```bash
RideBookingSystem.exe
```
